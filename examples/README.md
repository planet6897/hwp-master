# 예제

| 폴더 | 라우트 | 내용 |
|---|---|---|
| `m0/` | Default (M0 대조) | 개조식 보고서·사업계획서·기안문 HDS → HWPX, 한컴 2024 PDF, 실루엣 TSV |
| `report/` | Default | 개조식 보고서 2쪽 — 기획·단위 원고·HWPX, 한컴 2024 PDF, 실루엣 TSV, 재현 절차 |
| `template_fill/` | Template Fill | 자리표시 서식 + 자료 → 채운 HWPX, 한컴 2024 PDF, 실루엣 TSV |

각 폴더의 HWPX 는 한컴오피스에서 바로 열어 편집할 수 있다. 한컴 PDF 는 같은 HWPX 를 한컴오피스 2024 로
출력한 독립 기준이다.
