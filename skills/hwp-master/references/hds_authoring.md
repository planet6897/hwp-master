# HDS 작성법 (v1)

HDS v1은 `rhwp scaffold` 명세 v1과 같다. 지원하는 블록은 세 가지뿐이며, 그 밖의 필드나 블록은 오류(E002·E003)다.
미지원 표현을 그림이나 꼼수로 흉내 내지 않는다.

| 블록 | 필드 | 한글 문서에서 |
|---|---|---|
| `heading` | `level` 1~7, `text` | 개요 문단 (자동 번호, 굵게 12pt) |
| `paragraph` | `text` | 본문 문단 (10pt, 양쪽 정렬, 줄 간격 160%) |
| `table` | `rows` (문자열 2차원 배열), `cell_align` (선택) | 균등 열 폭 실선 표, 첫 행은 일반 행 |

## 오류가 되는 것

| 코드 | 내용 |
|---|---|
| E101 | 제목에 번호를 직접 씀 (`"1. 추진 배경"`, `"가. 개요"`, `"Ⅲ. 일정"`) → 한글이 자동 번호를 붙여 이중 번호가 된다 |
| E102 | 제목 수준이 1~7 밖 |
| E103 | 빈 제목 |
| E104 | 빈 표 |
| E005 | `cell_align`이 `justify`/`left`/`center`/`right`(또는 열별 목록)가 아님 |

## 경고

| 코드 | 내용 | 대응 |
|---|---|---|
| W201 | 셀 텍스트가 균등 열 폭 한 줄을 넘음 | 셀 문장을 줄이거나 열을 줄인다. 한컴에서는 줄바꿈되지만 rhwp 미리보기는 잘린다 (M0 F2) |
| W202 | 행마다 열 수가 다름 | 빈 셀로 채워진다. 의도가 아니면 맞춘다 |
| W203 | 빈 문단 | 간격용 빈 문단은 쓰지 않는다 |
| W301 | 단위 분량이 계획의 ±30% 밖 | 내용을 보강하거나 덜어 낸다 |

## 개조식 작성 (v1 임시 규약)

v1에는 목록 블록이 없으므로 기호를 문단 텍스트 앞에 직접 쓴다.

- 1단계 `□`, 2단계 앞에 공백 두 칸 + `○`, 3단계 공백 네 칸 + `-`
- 문장은 명사형으로 끝낸다 ("~함", "~임", "~필요"). 마침표를 찍지 않는다.
- 수치는 자료에 있는 값만 쓰고 단위를 붙인다.

## 표

- 머리행은 첫 행에 둔다. 숫자 열은 `right`, 구분 열은 `center`, 설명 열은 `left`.
- 열 폭은 균등하다(v1). 긴 설명이 필요한 표는 열 수를 줄이거나 표 아래 문단으로 설명한다.
